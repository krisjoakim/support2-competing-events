# Generated analysis results

The executed notebooks write reproducibility artifacts to three directories:

- development contains fold-level development results and the locked model JSON;
- tables contains aggregate validation, test, bootstrap, calibration, and ADL tables;
- bootstrap contains compressed replicate-level distributions;
- figures contains the selected public figures.

All tabular outputs are aggregate model results. No patient-level feature rows,
patient identifiers, or prediction exports are stored.

The complete directory can be regenerated by running notebooks 01 through 05 in
order with the pinned environment in requirements.txt.
