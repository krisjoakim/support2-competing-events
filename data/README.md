# Data access and provenance

Patient-level data is not committed to this repository.

## Source

The project used a course-distributed snapshot associated with the [SUPPORT2 dataset](https://archive.ics.uci.edu/dataset/880/support2) from the UCI Machine Learning Repository. The public dataset originates from the SUPPORT study and is maintained by the Vanderbilt University Department of Biostatistics. It contains demographic, physiological, disease-severity, outcome, and follow-up information for 9,105 critically ill patients treated at five US medical centres.

The upstream maintainers request acknowledgement of the original study and the Vanderbilt University Department of Biostatistics. The UCI record cites:

> Harrell, F. (1995). SUPPORT2 [Dataset]. UCI Machine Learning Repository. https://doi.org/10.3886/ICPSR02957.v2

The original study reference is:

> Knaus WA, Harrell FE, Lynn J, et al. (1995). The SUPPORT prognostic model: Objective estimates of survival for seriously ill hospitalized adults. *Annals of Internal Medicine*, 122, 191-203.

See the [Vanderbilt dataset page](https://hbiostat.org/data/) for its use and acknowledgement statement and the [SUPPORT description](https://hbiostat.org/data/repo/supportdesc) for dataset-specific context.

## Why the course files are excluded

The course snapshot is closely related to the current public UCI data but is not an identical redistribution:

- the modelling and prediction partitions contain 7,740 and 1,365 unique patient IDs respectively, forming a disjoint partition of all 9,105 public IDs;
- most retained source variables match the current UCI export after column renaming;
- the course files contain deliberately invalid ages and length-of-stay values used in the cleaning exercise;
- the DNR status and DNR-day fields were materially transformed in the modelling partition;
- the prediction partition withholds the length-of-stay target; and
- the data was split across four formats and renamed with Norwegian column labels.

No license or redistribution notice for these course-specific transformations was bundled with the project, so redistribution rights for the course snapshot could not be established. The local snapshot is therefore excluded from Git; access to the related public upstream dataset is documented separately above.

The repository's MIT License does not apply to any dataset.

## Expected local files

To reproduce the historical workflow exactly, obtain the original course snapshot and place it as follows:

```text
data/course/
├── raw/
│   ├── demographic.csv
│   ├── hospital.csv
│   ├── physiological.txt
│   └── severity.json
└── sample/
    ├── demographic.csv
    ├── hospital.csv
    ├── physiological.txt
    └── severity.json
```

The `physiological.txt` files are tab-delimited. The course snapshot is already present in these ignored locations for the original project owner, but it will not be included in a clone of the public repository.

## Generated files

Notebook 1 writes train, validation, and test CSVs plus merged intermediate data to `data/processed/`. Notebook 2 writes prediction-ready sample data to the same directory and a fitted model to `artifacts/`. Notebook 3 writes `results/predictions.csv`.

All of these files are reproducible artifacts and are ignored by Git. They should be regenerated by running the notebooks in order.

## Public-data limitation

The current UCI `data.csv` is useful for studying the upstream dataset, but it is not a drop-in replacement for the course files. Reproducing the exact historical metrics from UCI alone would require reconstructing undocumented course transformations and the withheld-target sample partition. This repository therefore does not claim full public-data reproducibility.
